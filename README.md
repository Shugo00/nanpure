# ナンプレ 1.0.0 ブラウザ版

GitHub Pages のゲームURLを開いて遊べます。初回はインターネット接続が必要です。
続きから遊ぶときは、同じ端末・ブラウザで同じURLを開いてください。

マスを選び、画面の数字ボタンかキーボードで入力します。16×16盤では、キーボードで数字を入力したあと Enter で確定します。

[使用部品・ライセンス・対応するソースのダウンロード](THIRD_PARTY.zip)
